xDrip+ pour CareSens Air (Android)

xDrip+ est l’intégration CareSens que Healthings utilise sur Android. Téléchargez-le ici et branchez une fois : CareSens Air → xDrip+ → Health Connect → Healthings.

Les termes kcal, BMR, CGM et les marques comme Withings restent en anglais.

Android seulement. Sur iPhone, xDrip+ n’existe pas — CareSens Air partage directement avec Apple Health. Voir Glucose CGM.

CareSens Air garde les mesures pour elle. xDrip+ est l’intégration CareSens sur Android : elle aligne CareSens avec Healthings. On branche une fois, ensuite le glucose arrive tout seul sur le tableau de bord.

xDrip+ est en anglais sur tous les téléphones : les libellés ci-dessous sont cités tels que vous les verrez.

Télécharger xDrip+ pour Android

Environ 16 Mo. L’intégration CareSens que Healthings utilise sur Android — cette version, code sur GitHub.

1. Installez xDrip+

  1. Touchez le bouton ci-dessus depuis le téléphone. Le navigateur alerte sur un APK — normal hors Play Store.
  2. Ouvrez le fichier téléchargé. Si Android refuse, autorisez Install unknown apps pour votre navigateur, puis rouvrez-le.
  3. Ouvrez xDrip+ une fois. Vous pouvez passer son assistant capteur — c’est CareSens Air qui alimente.

2. Laissez CareSens Air parler à xDrip+

  1. Dans l’app CareSens Air, ouvrez Manage Data & Connections.
  2. Activez xDrip+.

Laissez CareSens Air installée et active. Elle reste l’app qui parle au capteur ; xDrip+ ne fait qu’écouter.

3. Pointez xDrip+ vers l’app compagnon

Dans xDrip+ : Settings → Hardware Data Source → choisissez Companion App (les anciennes versions l’appellent 640G / Eversense). En quelques minutes, un chiffre doit apparaître sur l’écran d’accueil de xDrip+.

4. Envoyez les mesures vers Health Connect

  1. xDrip+ → Settings → Inter-app settings.
  2. Descendez jusqu’à Google Health Connect.
  3. Use Health Connect ON, Send data to Health Connect ON, Get data from Health Connect OFF.
  4. Touchez Manage permissions et laissez xDrip+ écrire Blood Glucose.

Laissez Get data from Health Connect désactivé. xDrip+ n’a qu’à écrire ici, et avec la lecture activée certains téléphones vous alertent toutes les quelques minutes.

5. Laissez Healthings lire le glucose

  1. Dans Healthings : Profil et réglages → GEAR → CGM = Oui.
  2. Autorisez Blood Glucose quand le téléphone le demande (Allow access).
  3. Touchez l’icône d’actualisation en haut. La bande du graphique devient GLUCOSE et se remplit.

Vous portez le capteur depuis quelques jours ? GEAR → Import charge l’historique CSV CareSens, pour que les jours passés ne soient pas vides.

Rien n’arrive ?

  • Laissez environ 15 minutes : la mesure traverse trois apps. Un capteur neuf est aussi en préchauffage les premières heures.
  • Vérifiez que CareSens Air est toujours installée et l’interrupteur xDrip+ toujours actif.
  • Réglages du téléphone → Health Connect → App permissions : xDrip+ peut écrire Blood Glucose, Healthings peut le lire.
  • Économiseur de batterie : laissez xDrip+ et Healthings tourner en arrière-plan. Android arrête d’abord les apps silencieuses.
