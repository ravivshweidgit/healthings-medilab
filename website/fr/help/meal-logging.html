Comment logger les repas

Loggez pour que le coach sous My Rules montre l’impact live sur les graphiques.

Les termes kcal, BMR, CGM et les marques comme Withings restent en anglais.

À retenir

  1. Touchez + sur le graphique métabolique.
  2. Photo — plate, puis validation.
  3. Texte — description ; l’IA sort les macros.
  4. Le chat peut proposer — sauvegarde via le food log.
