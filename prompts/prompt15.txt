## Prompt 15 — Release APK: Signed Local Build for Daily Use

### Goal
Produce a standalone release APK signed with a proper keystore that can be
installed on the device and run independently — no Metro bundler, no PC required.

### Install flow for signature mismatch
When switching from debug keystore → release keystore on same package name:
1. Export food log (⬆ Export → pick Downloads folder)
2. Uninstall debug app (Settings → Apps, or `adb uninstall com.healthings.medilab`)
3. `adb install android\app\build\outputs\apk\release\app-release.apk` (no `-r` flag on first install)
4. Re-link Withings OAuth
5. Import food log (⬇ Import → pick the JSON file)

For subsequent updates (same release keystore):
- `adb install -r ...` works without uninstall — data preserved

### What changes vs dev build

| Feature | Dev build | Release APK |
|---|---|---|
| Needs Metro running | Yes | No |
| Needs PC on same WiFi | Yes | No |
| JS bundle | Loaded from Metro | Bundled inside APK |
| Hermes JIT | Off | On (faster startup) |
| `__DEV__` | true | false |
| Console.warn logs | Visible | Suppressed |
| Mock data seeding | Active | Disabled |
| Gemini API key | Hardcoded | From .env (bundled at build time) |
