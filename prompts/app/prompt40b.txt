## Slash commands (nutritionist tab)

### Shipped (40a) — immediate single meal / recipe (Nutritionist tab)

**Not menu plans** — one `RecipePlan` card only. **Slash required** (no natural-language trigger).

**English slash tokens only** — hint after command may be Hebrew (e.g. `/recipe השייק הקבוע`). No Hebrew command tokens (RTL + regex reliability).

| Group | Commands | Meaning |
|-------|----------|---------|
| **Eat now** | `/eat` | One meal for **remaining macros today** (same RecipeCard UI) |
| **Recipe** | `/recipe` `/recipt` `/create` | One recipe card (+ optional hint) |

Also: **`/macros`** — macro targets (not a recipe).

Autocomplete: `/` picker on nutritionist tab; review shortcuts `/7` `/30` `/yesterday` on all tabs (`/7` hint: or type `/N` 1–128).

---

### Planned (40b+) — menu program (`/menu` prefix, English only)

**Separate feature** — multi-meal `DayPlan` / `WeekPlan` / month TBD. Never mixed with `/recipe`.

#### English — `/menu` family (accept `/menue` typo alias)

| Command | Output |
|---------|--------|
| `/menu` | One-line help: day / week / month subcommands |
| `/menu-d` …hint | Day menu → `DayPlan` card |
| `/menu-w` …hint | Week menu → `WeekPlan` card |
| `/menu-m` …hint | Month menu (TBD) |

#### Legacy aliases (still parse, map to menu-*)

| Old | Maps to |
|-----|---------|
| `/daily` | `/menu-d` |
| `/weekly` | `/menu-w` |

Bare `/menu` → **help only** (recommend: do not silently pick day vs week).

Today `/daily` and `/weekly` still return **“coming next”** until 40b ships.

**Context injected:** macro target, eaten today, food log history, **FoodPreferences** (40f), My Rules.

---

### Command mental model (final)

```
Immediate (now)     →  /eat
One recipe (doc)    →  /recipe /create /recipt
Menu program        →  /menu-*  (/daily /weekly legacy)
Macro targets       →  /macros
Data review         →  /7 /30 /yesterday /N  (all mentor tabs; N = 1–128)
```

Hint text after any command may be in the user's language (Hebrew OK).

---

### Command design notes

1. **`/menu` = menus only** — never route to `RecipePlan`.
2. **Everything else in the recipe list = one meal/recipe** — no day timeline.
3. **`/menue`** — optional typo alias for `/menu` in parser.
4. **English slash tokens only** — no Hebrew `/מתכון` etc. (40a follow-up).
5. **Month** — `/menu-m` stretch; ship day + week first.
6. **Wrong command:** `/recipe full day` → suggest `/menu-d`.

## JSON schemas

### `DayPlan`

```json
{
  "title": "Saturday lean day",
  "title_local": "יום רזה — שבת",
  "date_hint": "today",
  "meals": [
    {
      "slot": "breakfast",
      "time_hint": "08:00",
      "label": "Greek yogurt bowl",
      "label_local": "קערת יוגורט יווני",
      "recipe": { "...RecipePlan..." },
      "total_kcal": 420
    }
  ],
  "day_total_kcal": 2280,
  "day_total_protein_g": 141,
  "notes": "..."
}
```

### `WeekPlan`

```json
{
  "title": "Week of Jun 16",
  "title_local": "שבוע 16–22 ביוני",
  "days": [{ "weekday": "sun", "label": "Sunday", "day_plan": { "...DayPlan..." } }],
  "week_notes": "..."
}
```

Kitchen units: same AI rules as 40a (`amount_display` + `amount_display_local` + `grams`).
