## Problem

Healthings.AI leads **macro engine, data fusion, Activity / YouTube AI burn, language**. Competitor scorecard says we still lose the ICP race on **feel**:

| Gap | Score (ICP) | Competitor lead |
|-----|------------:|-----------------|
| UX / polish / retention | ~52 | Nutrisense ~88, Levels ~85 |
| Setup ease | ~56 | Libre / Withings ~88–90 |
| Human coach (solo) | ~25 | Nutrisense ~92 — **clinic RD path**, not this prompt |

Users with Libre + Withings + labs hit **setup friction**, **strip archaeology**, and **weak first-session aha** — so they never stick long enough to feel the engine advantage.

This prompt is **product polish + habit speed**, not a visual redesign of the brand and not “beat Cronometer food DB.”

## How to use LLMs / agents (process, not a feature)

Polish is **spec → small PR → phone**. Model choice is secondary:

| Work | Prefer |
|------|--------|
| RN layout / theme / i18n diffs | Coding agent against existing `ThemeProvider` + `*Copy.ts` |
| Microcopy | Same catalogs; always-English glossary unchanged |
| Taste / hierarchy | Owner decides on device; agent does not invent a new design system |

Do **not** open a broad “redesign dashboard” batch. One phase per ship.
