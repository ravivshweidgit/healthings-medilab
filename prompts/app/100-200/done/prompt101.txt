## Prompt 101 — Custom lab parameter historical chart

**Status:** done (2026-08-03) — **App phone-tested.** Clinic/account code shipped in same commit; portal deploy + verify still pending.

**Builds on:** prompt48 (lipid strips), prompt99 (`refLow`/`refHigh`), prompt39 (lab strip)

---

### Problem

Lipid trends already chart Total/LDL/TG/HDL with fixed adult thresholds. Users (and clinic/account viewers) also want a **historical chart for any other lab item** (e.g. TSH, creatinine, glucose) with a green **from–to** band from that item’s reference range.

---

### Locked decisions (owner 2026-08-03)

| Decision | Choice |
|----------|--------|
| Charts | **One** custom chart, **one** parameter |
| Picker | Dropdown with **filter / autocomplete**; options = union of markers across saved draws, **grouped by code** |
| Match | Exact **code** (aliases via existing code sets where applicable) |
| Lipid codes | **Exclude** LDL / total chol / HDL / TG (and their aliases) — dedicated lipid chart covers them |
| Green band | **`refLow`–`refHigh`** range fill (white outside) — not lipid-style single threshold |
| Range when draws differ | **One item → one range.** Latest draw that has both `refLow` and `refHigh` |
| Clinic / account | **Independent pick**; default to patient’s `lab_custom_trend_code`; viewer change is local only |
| Collapsible | Lipid + custom each collapsible (app under Lab Results; clinic/account Lipids tab) |
