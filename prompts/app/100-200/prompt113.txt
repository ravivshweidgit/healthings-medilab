# prompt113 — User country + country-scoped lab PDF models

**Status:** backlog (spec draft 2026-08-16)  
**Builds on:** prompt112 (IL HMO identify → confirm → layout pack)  
**Model to implement:** Opus/strong for Profile + defaulting rules; Auto for wiring packs

## Problem

prompt112’s Pass 1/2 prompts and provider enums are **Israel-only** (Clalit / Meuhedet / Maccabi / Leumit).
When the app goes global, one worldwide identify prompt will regress every country.

**Owner (2026-08-16):** separate lab models by **user country**. Language ≠ country
(Hebrew speaker abroad; English speaker in IL). Fine-tuning / prompt packs must key off country.

## Design

### 1. Persisted user country (canonical)

| Piece | Rule |
|-------|------|
| Key | Documented AsyncStorage key (e.g. `user_country`) — ISO 3166-1 alpha-2 (`IL`, `US`, …) |
| Not language | Never derive lab country from `user_language` alone |
| Default | Existing installs → `IL` (current product). New installs may suggest from device region, user confirms in Profile / Quick Start |
| Export / backup | Include in clinic snapshot + local/cloud backup (persistence-parity) |
| Clinic | Patient country is app-side; portal does not invent a second country field unless product asks |

### 2. Lab parse shell (same as prompt112)

```
country pack → Pass 1 identify (providers for that country)
            → user confirm
            → Pass 2 layout pack for confirmed provider
            → repairGaugeBoundCollisions (shared safety net)
```

| Country | Pass 1 providers (v1) | Pass 2 packs |
|---------|----------------------|--------------|
| `IL` | clalit, meuhedet, maccabi, leumit, unknown | Meuhedet gauge (shipped); others default |
| other | `unknown` / generic only until a pack exists | default + repair |

Do **not** grow one mega identify prompt for all countries.

### 3. Profile / QS UI

- Short row: **Country** (endonyms or English country names — no flags-as-language confusion).
- Lab import reads `getUserCountry()` before Pass 1.
- Non-IL with no pack: skip Israeli HMO chips; generic parse + clear “layout pack for your country coming” if needed.

## Out of scope (this prompt)

- Training a separate Gemini fine-tune per country (prompt packs first; fine-tune later if data warrants)
- Full US/EU provider catalogs on day one
- Changing lab `name` language policy (stays English at rest)

## What ships

| Piece | Change |
