## Prompt 64 — Health Connect activity (Garmin watch, no scale)

**Status: backlog (spec 2026-07-09)**  
**Builds on:** `done/prompt59.txt` (HC steps guide) · `done/prompt58.txt` (Your setup toggles) · `done/prompt55.txt` (`source_config`) · `done/prompt31.txt` (Samsung steps adapter)  
**Primary persona:** Colleague with **Garmin watch only** — no Withings scale. Uses CGM via Health Connect, logs meals in app, wants **named workouts** (walk/run) + **active kcal** in dashboard, coach, and clinic chat — same quality as Withings watch users.

---

### Problem

Today when **Withings watch = No**, `source_config.activity` routes to `samsung-steps`:

- Health Connect **Steps** only → daily step total → **estimated** active kcal (`stepsToActiveKcal`).
- **No** `ExerciseSession` read → no timed workouts on chart, coach, or clinic.
- Clinic mentor correctly says “no exercise logged” even after a 1-hour Garmin walk (fixed for Withings snapshot workouts in server `formatWorkoutsBlock`, but HC users have empty `workouts[]`).

Garmin Connect (2025+) syncs to Health Connect natively — **no Garmin web API** for Healthings (enterprise partner program only). Golden path: **read standard HC records on Android**, same code for Garmin, Samsung Health, Pixel Watch, etc.

---

### Design principle

| Device | Integration |
|--------|-------------|
| Withings scale / watch | Keep **Withings cloud OAuth** (`getworkouts`, `getactivity`, `getintradayactivity`) |
| Garmin / Samsung / other Android watches | **Health Connect** — not a “Garmin adapter” |
| iPhone + Garmin | Out of scope here → `prompt56.txt` (HealthKit) |

**Watch-only Garmin user defaults (Quick Start / My Profile):**

| Toggle | Value |
|--------|-------|
| Withings scale | **No** → `bodyComposition: manual`, `bmr: manual` or profile-based estimate |
| Withings watch | **No** → `activity: health-connect` (rename from `samsung-steps`) |
| CGM | Per user (Yes if CareSens/Libre → HC glucose) |

User must enter **height, weight, birthdate** manually for BMR and step fallback.

---

### Health Connect records to read

| HC record | Use in Healthings |
|-----------|-------------------|
| `ExerciseSession` | Timed workouts → unified `WorkoutSession` (label, start/end, duration) |
| `ActiveCaloriesBurned` | Session kcal (aggregate inside session window) + daily active total |
| `Steps` | Daily totals (existing); fallback kcal when calories missing |
| `HeartRate` | **Phase 2** — avg/max during session for coach + clinic (like Withings HR lines) |

**Do not** use `TotalCaloriesBurned` for active burn (includes BMR → double-count with app BMR).

**Permissions:** runtime + manifest declarations for `ExerciseSession`, `ActiveCaloriesBurned`, `Steps`; phase 2 add `HeartRate`. Consider `PERMISSION_READ_HEALTH_DATA_HISTORY` for clinic backfill beyond 30 days (document limitation).

---

### `source_config` change

Migrate on load:

```jsonc
// activity: rename
"samsung-steps" → "health-connect"

// heartRate (phase 2)
"none" | "withings" | "health-connect"
```

`sourceConfigFromToggles`: when watch off → `activity: 'health-connect'`, `heartRate: 'health-connect'` (phase 2).

Update [`sourceConfigLabels.ts`](app/src/logic/sourceConfigLabels.ts): chip text **“Health Connect activity”** (not “Samsung steps”).

---

### Unified activity model

Reuse existing [`WorkoutSession`](app/src/services/WithingsApiService.ts) shape everywhere:

```ts
{
  category: number;        // HC exerciseType mapped to number, or hash
  activityLabel: string;   // HC title or mapped type (Walk, Run, …)
  startMs: number;
  endMs: number;
  kcal: number;
  source?: 'withings' | 'health-connect';
}
```

**Persistence:** extend [`WithingsPersistedStore`](app/src/services/WithingsPersistenceService.ts) **or** new `healthings:activityStore` key — must land in **snapshot export** ([`ShareExportService`](app/src/services/ShareExportService.ts)) so clinic [`formatWorkoutsBlock`](server/src/services/geminiClinic.ts) sees sessions.

**Dedup / burn math:**

1. Named sessions → chart bars + coach WORKOUTS block.
2. Daily active kcal → prefer `aggregate(ActiveCaloriesBurned)` when Garmin writes it.
3. Fallback → `stepsToActiveKcal` only when no calorie records for that day.
4. Avoid double-counting steps + session kcal for same window (document rule in adapter).

**User setup copy (Garmin, no scale):**

1. Garmin Connect → Settings → **Health Connect** → enable sharing (activities, steps, calories as offered).
2. Healthings → My Profile → **Withings scale: No**, **Withings watch: No**, **CGM:** per user.
3. Enter height, weight, birthdate manually.
4. Tap **Allow** when Healthings requests HC permissions (Exercise, Active calories, Steps).
5. After a walk → **Refresh my data** → verify workout on trend/chart and in coach.
