## Prompt 77 — Quick Start UX (one question per screen)

**Status: done (2026-07-18)** — commit `df6f9a9`  
**Builds on:** `done/prompt76` (phone health), `done/prompt58` (Your setup), `done/prompt55` (wizard), Withings OAuth on dashboard

### Problem

Quick Start packed units + profile + three device toggles onto dense screens. Withings OAuth was deferred to the dashboard, so new users finished without linking. Device questions lacked plain-language help and Withings product clarity. Product photos of Withings SKUs were declined (IP + false SKU lock).

### Product rules

- One primary question per screen (not a chat bot).
- English UI chrome; Learn more → `healthings.ai/help/…`.
- Withings = **cloud account** (any scale/watch that writes metrics/activity) — not BLE SKU lock.
- Link Withings **in the wizard** when scale or watch = Yes (Skip still allowed).
- Gear art = **original illustrations** / meals plate PNG — not Withings product photography.

### Flow

1. Welcome + units  
2. About you (gender, height, birth date)  
3. Coach & meals language (+ mentor voice if he/ar)  
4. Withings scale? Yes/No + help + gear art  
5. Withings watch? Yes/No + help + gear art  
6. CGM? Yes/No + help  
7. **Link Withings** (only if scale or watch Yes)  
8. Starting weight  
9. Phone health allow (if watch No or CGM Yes)  
10. Optional PDFs  
11. AI targets  
12. Meal tip (meals plate) → Finish
