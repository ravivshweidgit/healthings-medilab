### Problems

1. **Single combined lipid chart** — Total, LDL, HDL, and TG shared one Y-axis; HDL/TG labels collided; trends were hard to read.
2. **Mentors saw only the latest draw** — Older lab imports were invisible in chat/coach USER DATA; users asking “how did my LDL change?” needed `/N` wide enough to cover both dates.

---

### What shipped

#### 48a — Four-strip lipid trend charts (dashboard)

**Component:** `app/src/components/LipidTrendChart.tsx`

Stacked mini-charts (energy-strip pattern), shown in `LabResultsStrip` when ≥2 draw days have lipid data:

| Strip | Safe zone (green band) | Direction |
|-------|------------------------|-----------|
| **TOTAL** | &lt; 200 mg/dL | Lower is better — fill below threshold |
| **LDL** | &lt; 100 mg/dL | Lower is better |
| **TG** | &lt; 150 mg/dL | Lower is better |
| **HDL** | ≥ 40 (male) / ≥ 50 (female) mg/dL | Higher is better — fill **above** threshold |

**Behaviour:**
- Each strip **auto-scales Y** from that metric’s values + always includes the target band in domain.
- One line + value label **below** each dot (no cross-series collision).
- Strips with &lt;2 data points for that metric are **hidden**.
- Shared X-axis (draw dates) at bottom; strip title shows target (e.g. `LDL · <100 mg/dL`).
- Disclaimer: *General adult targets — not medical advice* (EN) / Hebrew equivalent when RTL.
- With only one draw: hint *Import another draw to see cholesterol trends* (no chart).

**Data helper:** `buildLipidTrendPoints(reports)` in `LabLogService.ts` — one row per draw day, fields: `ldl`, `totalCholesterol`, `hdl`, `triglycerides`.

**Gender:** `DashboardScreen` passes `userGender` → `LabResultsStrip` → `LipidTrendChart` for HDL threshold.

#### 48b — All saved lab draws in mentor USER DATA

**Service:** `LabLogService.getLabsAiContextForHeader()`

- Loads **all** reports via `getAllLabReports()`.
- Formats with `buildLabsAiContext(reports, 'all')`:
  ```
  LAB RESULTS (N saved draws — local PDFs, not medical advice):
  Report 2026-06-16 (Clalit) — chemistry:
    ...
  Report 2026-06-29 (Clalit) — chemistry:
    ...
  ```

**Where injected (unchanged paths, expanded scope):**

| Surface | Function | When loaded |
|---------|----------|-------------|
| Chat | `buildFreshContext()` → `getLabsAiContextForHeader()` | Every send |
| Coach panel | `buildProfileTargetsHeader()` via `labsAiContext` | Every `generateCoachMessage()` / refresh after lab save |

**Coach refresh on lab save:** `loadLabReports(true)` in `DashboardScreen` calls `triggerCoachReview` so panel picks up new labs without opening chat.

**Period review (`/N`):** unchanged — still uses `getLabReportsForDayKeys` + `buildLabsAiContext(..., 'history')` for window-scoped history.
