## Prompt 87 — Dashboard chrome i18n (Phase B)

**Status: done (2026-07-22)** — phone-tested Android (Samsung, iterative bi). Commit `3858d8b`.  
**Builds on:** `done/prompt81` (Phase A), backlog `prompt81b` (this ships Phase B)  
**Refines:** `done/prompt62` (AI chat label), `done/prompt85` (Reports), `done/prompt86` (Food Log collapse)

### Problem

After Phase A (language gate + Quick Start + help), Dashboard / Food Log / Profile chrome stayed English. Hebrew-first alpha users saw mixed UI: coach language in meals/chat, English strip titles and dates.

### What shipped

| Area | Behavior |
|------|----------|
| **Food Log title** | 7-locale titles (`יומן ארוחות` HE); HE/AR collapsed balance uses color only (no `+`/`−`) |
| **Glucose / Activity / Trend** | Titles + status (`No reading`, `no CGM`, ago) via `metabolicStripCopy.ts`; brands stay English |
| **PROFILE & SETTINGS** | Localized title; collapsed summary (gender, age, mentors); HE/AR bare numbers (no `cm` / age unit) |
| **Profile nested strips** | Bare nouns (no “My/שלי”): Profile, Targets, Mentors, Rules, Macros, Account, Data sharing, Reports, App Backup |
| **AI chat** | Keep “AI”; localize “chat” only (`AI שיחה` HE) via `aiChatCopy.ts` |
| **Body metrics** | Weight / Fat / Muscle labels via `bodyMetricsCopy.ts` (body card, trend, targets, manual body) |
| **Dates** | Coach-language locale via `dateLocale.ts` (Food Log, charts, labs, birthdate, meal modal) |
| **Strip header unify** | All dashboard strips use `DashboardCollapseHeader` (shared fonts/styles); Profile sub-rows migrated |
| **App Backup** | Collapsible `LocalBackupStrip`; Export / Import buttons localized |
| **Reports collapsed** | Numbers only: `7 / 14 / 30 / 90` |
| **Data sharing** | Subtitle i18n (whitelisted / empty / waiting / shares with) |

### Always-English glossary (unchanged)

`kcal`, `CGM`, `BMR`, Withings, Health Connect, Apple Health, slash commands, brand.
