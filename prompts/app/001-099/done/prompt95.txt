## Hard constraints (do not fight)

- **No clinical-number or data changes.** F3 re-presents the *same* values — no recompute,
  no unit change. Keep the documented chart color map (weight/fat/muscle/visceral/
  glucose/HR) consistent everywhere.
- **RTL alignment by detected script only** (F13) — presentation. Do **not** parse rule/
  directive *meaning*; detect script (existing Hebrew/Arabic detection) and set
  `textAlign`/`writingDirection`. No new rules-text regex (ai-judgment rule).
- **No new AsyncStorage keys / no changed collapse or refresh semantics** (persistence-parity).
- Icons come from `theme/icons.tsx` (add to registry, don't scatter Lucide imports).
- Chat message **bodies/exports keep emoji**; only toolbar chrome changes (F8).
- Website: help path locale stays `/{lang}/help/…` (language-policy); clinic portal untouched.
