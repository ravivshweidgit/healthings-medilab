## Prompt 40a — Nutritionist recipe cards (single meal / `/eat` / `/recipe`)

**Status: done (2026-06-20)** — Shipped and phone-tested.

Commits: `0709809` (recipe cards) + follow-up (slash-only, English commands, autocomplete, food-log refresh).

Spec split: **40b** → `prompts/app/001-099/prompt40b.txt` (day/week plans, export, preferences).

Builds on **prompt39** (food log history) and **MacroProposalCard** pattern (`/macros`).

---

### Design principle

> **Chat = conversation. Viewer = document.**

Short chat intro + **RecipeCard** → **RecipeViewerModal** — not HTML in the bubble.

---

### What shipped

#### Recipe pipeline

- `mealPlanTypes.ts` — `RecipePlan`, `RecipeIngredient`, `finalizeRecipePlan`
- `recipePlanService.ts` — `generateRecipePlan()` structured JSON
- Kitchen units from **AI only**: `amount_display` (English) + `amount_display_local` (user language) + `grams` for food log
- No code-side unit translation (i18n-safe)

#### Chat (nutritionist tab)

- `RecipeCard.tsx`, `RecipeViewerModal.tsx`
- `ChatScreen` branch: recipe slash → card (like `/macros`)
- `FoodLogModal` prefill from **Log as meal**
- **`SlashCommandSuggestions.tsx`** — `/` autocomplete picker
- **`chatSlashCommands.ts`** — catalog + filter (English tokens; hints localized)
- Food log refreshes after **Log as meal** from chat (`DashboardScreen` → `onFoodLogSaved`)

#### Slash commands — English tokens only

**Slash required** — natural language (e.g. "build me a shake") stays normal chat, no recipe card.

| Group | Commands | Meaning |
|-------|----------|---------|
| **Eat now** | `/eat` | Recipe card scaled to **remaining macros today** |
| **Recipe** | `/recipe` `/recipt` `/create` | Faithful recipe card (+ optional hint in any language) |
| **Macros** | `/macros` | Macro target revision (not a recipe) |
| **Review** | `/7` `/30` `/yesterday` or any `/N` (1–128) | Period review (all mentor tabs) |

**Hint after command** can be Hebrew: `/recipe השייק הקבוע`

**Why no Hebrew slash tokens** (`/מתכון`, `/בנה`, …): JS `\b` word boundaries fail on Hebrew; RTL input reordering. Industry norm: English `/commands` + localized hints.

**Menu deferred (40b):** `/menu` `/menu-d` `/menu-w` `/daily` `/weekly` → parse but return “coming next” hint only.

#### Autocomplete (`/` picker)

- Nutritionist: `/eat`, `/recipe`, `/create`, `/recipt`, `/macros`
- All tabs: `/7`, `/30`, `/yesterday` — `/7` hint notes “or type /N (1–128)”
- No `/1` in picker (`/yesterday` or typed `/1` still work)
- Recipe commands ranked first on nutritionist tab; scrollable list (no 8-item cap)

#### `/eat` vs `/recipe`

| | `/eat` | `/recipe` |
|---|--------|-----------|
| Mode | `eat_now` | `recipe` |
| Sizing | Fits **remaining macros today** | Faithful recipe |
| UI | Same **RecipeCard** | Same **RecipeCard** |
| History hint | Rebuild + optional scale | Copy from log |

#### Rebuild from food log (40a2)

- `formatFoodLogHistoryForMealAi()` injected into recipe prompt
- Same history engine as prompt39; different surface (recipe card vs food log add)

#### Food log UX (bundled with 40a test pass)

- 2-line item rows (name full width; kcal + P/C/F/Fi below)
- Shorter `name_local` prompt in `GeminiService` (~25–35 chars)
- `mentorChatText.ts` strips `<i>`, `<b>`, etc.
