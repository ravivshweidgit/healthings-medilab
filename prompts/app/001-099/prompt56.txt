## Prompt 56 — iOS alpha (shared UI, HealthKit services layer)

**Status: partial (Phase B glucose — 2026-07-12; Phase C steps/HR — 2026-07-17 in `done/prompt76`)** — HealthKit blood glucose on TestFlight; steps/HR via Apple Health when Withings watch is off (prompt76).  
**Priority:** CareSens Air phone verify when sensor arrives  
**Builds on:** `done/prompt55.txt` · `done/prompt65.txt` Phase A (Withings-first TestFlight) · `done/prompt76.txt` · `prompt47.txt`

---

### Problem

iPhone friends cannot join alpha: no iOS binary, no TestFlight, health layer hard-coded to **Android Health Connect + Samsung steps**. The **UI is already cross-platform** (React Native); only the **services / permissions / build pipeline** differ.

User mental model (correct):

- **Same app** — dashboard, food log, coach, My Rules, Quick Start, Withings OAuth, lab/nutrition PDFs  
- **Different backends** — Android: Health Connect + Samsung steps; iOS: **HealthKit** (+ Withings, manual, CSV CGM import)  
- **`source_config`** drives which adapter runs — platform is a **configuration + adapter** issue, not a second product  

---

**iOS internal alpha (TestFlight)** with parity on **core coaching loop**:

```
                    ┌─────────────────────────────────┐
                    │  Shared UI (screens, wizard)     │
                    └───────────────┬─────────────────┘
                                    │
                    ┌───────────────▼─────────────────┐
                    │  source_config (v2)            │
                    │  + platform defaults           │
                    └───────────────┬─────────────────┘
          ┌─────────────────────────┼─────────────────────────┐
          ▼                         ▼                         ▼
   HealthConnectService      HealthKitService (NEW)     Withings / Manual / CSV
   (Android only)            (iOS only)                 (both platforms)
```

### Build & release (you do not need a Mac for every build)

| Requirement | Who / what |
|-------------|------------|
| **Apple Developer Program** | ~$99/yr — you enroll once |
| **Mac** | **Optional** if using **EAS Build** (Expo cloud builds iOS on their Macs) |
| **First-time setup** | Apple credentials in EAS, bundle id `com.healthings.medilab`, HealthKit capability |
| **TestFlight** | EAS Submit or manual upload to App Store Connect |
| **Tester invite** | App Store Connect → Internal testing (similar to Play internal) |

**Windows dev machine OK** for: JS/TS, `eas build --platform ios`, TestFlight upload.

**Mac needed locally only if:** debugging native HealthKit issues without EAS, or avoiding EAS cost.
