## PART A — Fiber↔carb coupling (`macroFiberCoupling.ts`)

### Hard constraints (always)

```ts
/** Fiber grams cannot exceed total carb grams (fiber ⊆ carbs on labels). */
export function clampFiberToCarbs(fiber_g: number, carb_g: number): number {
  return Math.min(Math.max(0, fiber_g), Math.max(0, carb_g));
}
```

### Recommended fiber target from carb target

From device chat conclusion (user + nutritionist agreed):

```ts
const LOW_CARB_FIBER_THRESHOLD_G = 45;
const STANDARD_FIBER_TARGET_G = 30; // general 25–35g band when carbs are not very low

/**
 * When carbs are very low, aim for ~⅔ of carb grams as fiber (quality low-carb sources).
 * When carbs are higher, cap at standard daily fiber — do NOT use ⅔ of 100g (= 66g).
 */
export function deriveFiberTargetFromCarbs(carb_g: number): number {
  const c = Math.max(0, carb_g);
  if (c <= LOW_CARB_FIBER_THRESHOLD_G) {
    return clampFiberToCarbs(Math.round((2 / 3) * c), c);
  }
  return clampFiberToCarbs(STANDARD_FIBER_TARGET_G, c);
}
```

**Examples:** 30g C → 20g Fi · 45g C → 30g Fi · 100g C → 30g Fi (not 66g).

**Locked (2026-06-17):** on **every new scale weight**, the nutritionist brain **reviews** current
macro targets against weight, goal, burn, and My Rules. If an update is needed → **`saveMacroTarget()`

|-------|--------|

**Deferred (not v1):** rules/body-target save alone, burn-only shift.

```

### How CGM should change macros (revision prompt rules)

CGM primarily validates **carbs** and **fiber quality**, not total kcal:

| CGM picture (7d) | Macro lever |
|------------------|-------------|
| Stable avg, most readings 70–100, few meal spikes | **Hold** carb cap; taper **kcal** from weight/burn only |
| Frequent post-meal spikes / problem foods in block | **Do not raise** carbs; keep or tighten cap; mention foods in `reasoning` |
| Many readings >140 or sharp meal spikes | **Hold or reduce** carb target before cutting protein |
| Lows <70 (trusted days, not warm-up) | **Do not cut kcal further**; flag in reasoning |
| No CGM data | Ignore glucose; use My Rules carb cap + weight/burn |

CGM does **not** override My Rules hard carb cap. It informs whether the current cap is working.

Add to `reviseMacroTargetsWithGemini` prompt:

```

- MUST cite period avg, min, max (mg/dL) in reasoning when CGM present.
- Use meal-spike / problem-food lines to justify carb and fiber targets.
- Do not set fiber_g > carb_g; use derive rule (⅔ of carbs when carbs ≤45g).
- kcal deficit/surplus comes mainly from weight goal + 7d burn, moderated by CGM stability.

### Deterministic fallback (Gemini offline only)

**Goal direction** from `startWeight_kg` vs `targetWeight_kg`:
- **Loss:** deficit while above target; maintenance at/past goal
- **Gain:** surplus while below target; maintenance at/past goal

**Kcal taper** from kg-to-goal (smooth, no ±500g band):

```ts
type GoalDirection = 'loss' | 'gain' | 'maintain';

function goalDirection(startKg: number, targetKg: number): GoalDirection {
  if (Math.abs(startKg - targetKg) < 0.5) return 'maintain';
  return startKg > targetKg ? 'loss' : 'gain';
}

/** kcal adjustment vs maintenance burn. Negative = deficit, positive = surplus. */
function kcalAdjustmentFromGap(
  weightKg: number,
  targetKg: number,
  direction: GoalDirection,
  burnKcal: number,
): number {
  if (direction === 'maintain') return 0;

  if (direction === 'loss') {
    const gapKg = weightKg - targetKg; // >0 still above goal
    if (gapKg <= 0) return 0; // at or below goal → maintenance
  // ~150 kcal deficit per kg still to lose, clamped 200–500
    return -Math.min(500, Math.max(200, Math.round(gapKg * 150)));
  }

  // gain
  const gapKg = targetKg - weightKg; // >0 still below goal
  if (gapKg <= 0) return 0;
  return Math.min(400, Math.max(200, Math.round(gapKg * 120)));
}

// targetKcal = burnKcal + adjustment
```

**Examples (target 80 kg, loss, burn 2400):**
- 84 kg (gap 4) → −500 → **1900 kcal**
- 81.4 kg (gap 1.4) → −210 → **2190 kcal**
- 80.0 kg (gap 0) → **2400 kcal** maintenance
- 79.5 kg (past goal) → **2400 kcal** maintenance (no further cut)

**Examples (target 85 kg, gain, burn 2400):**
- 82 kg (gap 3) → +360 → **2760 kcal**
- 85 kg → **2400 kcal** maintenance
