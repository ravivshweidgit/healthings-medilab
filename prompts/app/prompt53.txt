## Prompt 53 — Import nutritionist session reports (directive history)

**Status: backlog (spec draft 2026-07-03)**  
**Builds on:** `prompt39` / `LabReportModal` (PDF pick + Gemini parse) · `prompt46.txt` (medical/clinic plan authority) · `prompt51.txt` (history pattern) · `prompt52.txt` (rawText-only rules — directives are **separate** from My Rules).

**Fixture (local dev, do not commit):** `app/סיכום מפגש ראשון.pdf` — Hebrew first-session summary (goals, menu targets, sample day menu, macro totals, tasks). Use for parse QA only.

---

### Problem

Patients receive **nutritionist / clinic session PDFs** (e.g. *סיכום מפגש ראשון*) with:

- Clinical goals (LDL, weight, HDL)
- Prescribed macro bands (protein g/kg, fiber, saturated fat %)
- Example daily menu (breakfast / lunch / dinner)
- Tasks (next labs, supplements)
- Provider contact

Today there is **no import path** — user must manually copy fragments into **My Rules**, losing structure and prior sessions. `prompt46` plans a single “medical plan” overwrite; real care is **serial session reports** (visit 1, visit 2, …).

---

### Product decision (locked 2026-07-03, revised)

| Rule | Detail |
|------|--------|
| **Separate stores** | **Directives** = imported PDF archive (full session). **My Rules** = your working dietary notes (`user_rules`). |
| **Append directives** | Each import adds to directive history. Latest = **active directive** by default. |
| **No report count cap** | Keep **all** imported reports on device (like lab reports). Text-only storage is small (~5–15 KB/report); include in backup. No silent drop — user deletes manually if needed. |
| **Authority at runtime** | For AI (mentors, macros, meal check): **active directive > My Rules** on conflict. |
| **Update My Rules from report** | **Yes — optional, user-confirmed.** After import (or from directive detail): **“Update My Rules from this report”** merges compatible content into `user_rules`. See flow below. |
| **Parse** | Gemini extracts structured sections + `fullText`; user reviews before save. |
| **No summarise-on-save** | Directives and My Rules updates use **verbatim text** (`prompt52`). |
| **PDF file** | Parsed text + metadata in MVP; optional PDF bytes in cache (v2). |
| **Clinic push** | Defer to `prompt49d` / `prompt46` — patient import first. |

### User flow

```
Dashboard → Nutrition directives strip
  → Import PDF → Gemini parse → Review screen
  → Save → append to directive history; set as active
  → optional: "Update My Rules from this report" (see below)
  → optional: "Use macro summary as starting point" → macro strip (user confirm)
```

#### Update My Rules from report (optional)

When directive and personal rules **don’t need to fight**:

```
After save (or from directive detail) → "Update My Rules from this report"
  → Build candidate text from directive: goals + menuTargets + guidelines
     (exclude sample menu bullets, tasks, contact — or user toggles sections)
  → If existing My Rules empty → pre-fill candidate → user edits → Save
  → If My Rules exist:
       Gemini diff: conflicts[] vs compatible additions
       UI: show conflicts (amber) + "Will add" (green)
       Buttons: Merge compatible · Replace with report text · Cancel
  → Save uses prompt51 history (archive old user_rules before write)
```

| Case | Behaviour |
|------|-----------|
| No My Rules yet | One-tap fill from report; user can trim before Save |
| Compatible additions | **Merge** — append new lines to `rawText` (dedupe near-duplicates) |
| Conflicts | Show both sides; **directive still wins for AI**; user chooses what lands in My Rules for their own reference |
| User declines | Directive alone is enough — mentors still see full directive block |

**Not automatic** — import does not silently overwrite My Rules. User opts in per report.

**History list**

- Row: `{title or filename} · {sessionDate or importedAt}`
- Badge **Active** on current directive
- Tap → read-only detail (all sections)
- Actions: **Set active** · **Delete** (confirm)

**Replace active**

- Importing always adds history; new import becomes active unless user picks another from list.

### Data model (phone)

AsyncStorage key: `nutrition_directives_v1`

```ts
export type NutritionDirective = {
  id: string;
  importedAt: string;       // ISO
  sessionDate: string | null; // from PDF if parsed
  title: string;            // parsed or filename
  sourceFileName: string | null;
  fullText: string;         // authoritative blob for AI
  goals: string[];
  menuTargets: string[];
  sampleMenu: string;       // markdown or plain multiline
  macroSummary: string | null;
  guidelines: string[];
  tasks: string[];
  providerContact: string | null;
  lang: 'he' | 'en' | 'mixed' | null;
};

export type NutritionDirectivesStore = {
  activeId: string | null;
  entries: NutritionDirective[];  // newest first — unbounded; user deletes to free space
};
```

Service: `NutritionDirectiveService.ts` — `importFromPdf`, `list`, `getActive`, `setActive`, `delete`, `append`.

New: `proposeMyRulesUpdateFromDirective(directive, currentRules)` in `GeminiService.ts` → `{ mergedText, conflicts: { topic, directiveLine, myRulesLine }[], additions: string[] }`.

New: `applyMyRulesFromDirective(...)` — uses `saveUserRulesWithHistory` (`prompt51`).

### Gemini parse

New: `parseNutritionDirectivePdf(base64, lang?)` in `GeminiService.ts` (mirror `parseLabReportPdf`).

**Output JSON schema** (strict):

```json
{
  "title": "סיכום מפגש ראשון",
  "sessionDate": "2026-07-02",
  "goals": ["..."],
  "menuTargets": ["..."],
  "sampleMenu": "ארוחת בוקר: ...",
  "macroSummary": "1690 kcal · P112 · ...",
  "guidelines": ["..."],
  "tasks": ["..."],
  "providerContact": "...",
  "fullText": "..."
}
```

Prompt rules:

- Preserve **numbers and Hebrew** verbatim in `fullText` and section arrays
- Do not invent items not in PDF
- `sessionDate`: DD.MM.YY or explicit date in header → ISO
- If parse fails partially, still return `fullText` from OCR layer; user can edit review screen

### AI injection

```
=== NUTRITIONIST DIRECTIVE (active — authoritative over My Rules) ===
Title: ... · Session: ...
Goals:
- ...
Menu targets:
- ...
[sample menu excerpt if present]
Guidelines / tasks: ...
Full text:
{fullText}
```

Inject in:

- `GeminiService` coach / chat context (before My Rules block)
- `formatMacroRevisionRulesBlock` / macro suggest (directive menu targets as HARD bands when numeric)
- `checkMealAgainstUserRules` — check directive **then** My Rules
- Visit report appendix (optional section “Active nutritionist plan”)

**Do not** auto-change `daily_macro_target` on import — offer button **“Use macro summary as starting point”** → opens macro strip with values pre-filled for user confirm (`prompt35`).

- [ ] Local backup restore → full directive history preserved
