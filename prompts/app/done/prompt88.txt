## Prompt 88 — Dashboard chrome i18n follow-up (Profile, Food Log, labs, chart legend)

**Status: done (2026-07-24)** — phone-tested Android (iterative bi).  
**Builds on:** `done/prompt87` (Phase B dashboard chrome)  
**Refines:** `done/prompt58` (Your setup labels), `done/prompt70` (Food Log energy lines), `done/prompt39` (lab results strip)

### Problem

Phase B localized strip titles, but many Profile / Food Log / chart chrome strings stayed English: Gender/Height/Birth Date, Food Log energy lines and meal slots, Lab Results, Your setup, and chart legend (Glucose / Heart rate / Steps cal / Workout). Long RTL/Cyrillic legend labels also overflowed or failed to stack into two rows.

### What shipped

| Area | Behavior |
|------|----------|
| **Lab Results** | 7-locale strip + modal titles via `labResultsStripCopy.ts` (RU: РЕЗУЛЬТАТЫ АНАЛИЗОВ) |
| **Your setup** | Title, Yes/No, Save, scale/watch/CGM labels + hints via `yourSetupCopy.ts`; CGM brand stays English |
| **Profile form** | Gender / Male / Female / Other / Height / Birth Date / Age via `yourSetupCopy` |
| **Food Log chrome** | eaten / activity / burned / deficit·surplus, Meal, Water, Breakfast–Dinner (+ Snack) via `foodLogUiCopy.ts` |
| **Meal button** | Always **Meal** (removed “Meal here” for past days) |
| **Macros collapsed** | Subtitle keeps `P/F/C/Fi/Net` only (no update time) |
| **Chart legend** | Localized Glucose, Heart rate, Steps (not “Steps cal”), Workout; BMR stays glossary |

| **Blue unify** | Yes/No toggles, gender chips, Profile Save → `WellnessColors.accentBlue` |

`kcal`, `CGM`, `BMR`, Withings, Health Connect, Apple Health, unit symbols, slash commands.
