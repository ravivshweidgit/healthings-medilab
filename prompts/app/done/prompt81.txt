## Prompt 81 — Multi-language Phase A (language gate + Quick Start + help)

**Status: done (2026-07-21)** — Phase A phone-tested on Samsung; user LGTM.  
**Builds on:** `language-policy.mdc`, `done/prompt77` (Quick Start), `done/prompt72` (units)  
**Deferred:** Phase B Dashboard / Profile UI Hebrew → **shipped in `done/prompt87.txt`** (was `prompt81b`)

### Problem

Alpha users are Hebrew-first. English-only Quick Start and help `?` links caused friction and broken trust after choosing Hebrew.

### What shipped

| Area | Detail |
|------|--------|
| Language gate | Pre-Welcome, locale-neutral: logo (wordmark crop), intense multilingual **Select language** lines + 7 flag grid (4+3), English default, persist on Next |
| Quick Start copy | EN + native-tone HE (`quickStartCopy.ts`); RTL for he/ar; mentor voice for he/ar |
| Units section | Localized row labels (`unitsSectionCopy.ts`); glossary units stay EN |
| Help URLs | `helpUrl(lang, slug)` → `https://healthings.ai/{lang}/help/{slug}.html` for en/he/es/fr/de/ar/ru |
| Website help | 7 locale trees under `website/{lang}/help/`; 7-flag switcher; legacy `/help/` → 301 `/en/help/` |
| Deploy | `deploy-website.sh` nginx rewrite; live on healthings.ai |

### Always-English glossary (unchanged)

Brand, units (`kcal`, `mg/dL`, `kg`), acronyms (`CGM`, `BMR`), devices (Withings…), slash commands, `My Rules` / `My Profile` product names as used in UI.

| Path | Role |
