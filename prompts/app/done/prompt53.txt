## Prompt 53 — Import nutritionist session reports (directive history)

**Status: shipped + closed 2026-07-03** (phone import `[x]` · clinic Nutrition reports tab `[x]` — user accepted MVP, no further 53 polish)  
**Commits:** `b2c1cd3` (phone) · `5343c1a` (clinic tab)  
**Builds on:** `done/prompt39.txt` (PDF pick + Gemini) · `prompt52` rawText-only intent · `done/prompt51.txt` (history pattern — orthogonal store)

---

### Problem

Nutritionist session PDFs (e.g. *סיכום מפגש ראשון*) had no import path — users copied fragments into My Rules, losing visit history and clinic authority at runtime.

---

### What shipped (MVP)

| Area | Change |
|------|--------|
| Storage | `NutritionDirectiveService.ts` — `nutrition_directives_v1`, unbounded history, `activeId` |
| Parse | `parseNutritionDirectivePdf()` — Gemini transcribes PDF to **plain `fullText` only** (+ optional `title`, `sessionDate`, `lang`); prompt emphasizes `\n\n` between sections, one bullet per line |
| Review | `NutritionDirectiveReviewModal.tsx` — editable title/date + single report text body |
| Dashboard | `NutritionDirectivesStrip.tsx` — LabResultsStrip-style card at bottom; horizontal chips; import / view / set active / delete |
| AI | `nutritionDirectiveContext.ts` — active directive block before My Rules in coach, chat, meal check |
| Export | `ShareExportService.ts` — `nutrition_directives_v1` in snapshot blob |
| Backup | Included via generic AsyncStorage export (not excluded) |
| Clinic portal | `website/clinic/clinic-workspace.js` — **Nutrition reports** tab; read-only chips + plain `fullText` from snapshot |

**Product rules (shipped):**

- Directives **separate** from My Rules; latest import = active by default
- **Verbatim plain text** — no structured goals/menu fields in UI or storage (legacy structured entries migrated to `fullText` on read)
- Active directive **wins over My Rules** in AI context on conflict
