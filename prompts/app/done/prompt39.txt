### Goals

#### 39a — Natural-language references to past meals (food log)

User can type phrases like:

| User says | Expected behavior |
|-----------|-------------------|
| "add last evening's shake" / "הוסף את השייק מאתמול בערב" | Copy items from matching history entry |
| "my usual shake" / "השייק הרגיל שלי" | Use **FREQUENT MEALS** pattern (≥2 repeats in window) |
| "same chicken breast meal" / "אותה ארוחת עוף" | Match by food names + recent time |
| "הוסף כף קינמון" | Normal add — estimate new item (not history) |
| "chicken 100→200" / correction on result screen | Update **current conversation** meal JSON |

#### 39b — Dashboard UX

Move **Lab results** strip to the **bottom** of the dashboard scroll (least-used section).

### What shipped

#### 39a — Food log history pipeline

1. **`foodLogMealHistory.ts`**
   - `computeFrequentMealPatterns()` — recurring meals (signature = sorted item names + grams)
   - `formatFoodLogHistoryForMealAi()` — compact block for prompt injection
   - 14-day lookback; excludes meal being edited
   - Per meal: id, date/time, day part (morning/afternoon/evening/night), items + macros
   - **FREQUENT MEALS** footer for "usual" / "regular"

2. **`GeminiService.ts`**
   - `buildFoodSystemPrompt(lang, userRules, foodLogHistory?)` — appends history + **FOOD HISTORY RULES**
   - `analyzeFood(..., foodLogHistory?)` — passes history into system prompt
   - Rules: match past meals from history; corrections use conversation JSON, not history

3. **`FoodLogModal.tsx`**
   - Loads `getRecentMeals(14)` when modal opens
   - `resolveFoodLogHistory()` — ensures block ready before each analysis (race-safe)
   - Wired on: text submit, photo analysis, chat correction
   - Hebrew/English placeholders hint at history phrases

#### 39b — Dashboard

- `DashboardScreen.tsx` — `LabResultsStrip` moved below My Profile / backup card

### Architecture

```
FoodLogModal (visible)
  → getRecentMeals(14)
  → formatFoodLogHistoryForMealAi(entries, { excludeEntryId, lookbackDays: 14 })
  → analyzeFood(..., foodLogHistory)
       → buildFoodSystemPrompt(..., foodLogHistory)
            → SYSTEM_PROMPT + user rules + FOOD LOG HISTORY + FOOD HISTORY RULES
```

**Separation of concerns**

| Context | Used for |
|---------|----------|
| `foodLogHistory` (system prompt) | "yesterday", "usual", "same as last time" |
| `mealHistory` (GeminiTurn[]) | Corrections to current meal in modal |
| Fresh text / photo | New meal estimate (USDA-style) |
