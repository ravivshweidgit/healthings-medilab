## Phase 2 — Manual low-corruption exclusions (after Phase 1 on live CGM)

Users mark **specific time ranges** as sensor corruption (compression lows). Automatic warm-up +
stat filters already exist.

### Anti-cheat (hard)

| Range max | User can exclude? |
|-----------|-------------------|
| All samples **< 65 mg/dL** | Yes |
| Any sample **≥ 65 mg/dL** | **No** — blocked |

### UX
1. Long-press or **Edit CGM** on `MetabolicChart` → select time range
2. If `max < 65` → confirm "Mark as sensor error"; else disabled message
3. Grey excluded segments on chart; mentors ignore those points
4. **Manage exclusions** list with Undo

### Storage
```ts
export type CgmManualExclusion = {
  id: string;
  startMs: number;
  endMs: number;
  maxMgDl: number;       // < 65 at creation
  reason?: 'sensor_error';
  createdAt: string;
};
// key: cgm_manual_exclusions
```

Apply in `prepareGlucoseSeries()` after warm-up + stat filters.
Mentor line when active: `USER-EXCLUDED SENSOR ERRORS: N windows (all peaks <65 mg/dL)`.

**Files:** new `cgmManualExclusions.ts`, `healthMetricsCache.ts`, `MetabolicChart.tsx`, `DashboardScreen.tsx`, `mealGlucoseAnalysis.ts`
