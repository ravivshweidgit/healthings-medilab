## Prompt 71 — H2O macro + meters (manual water)

**Status: done (2026-07-16)** — Phone-tested on Samsung.  
**Builds on:** Food Log meters (`done/prompt70.txt`).  
**Commit:** `c85d6ec`

### Problem

No hydration tracking. Users need a simple daily water meter next to kcal/P/C/F/Fi, with goal editing that does not require coach AI.

### What shipped

| Area | Behavior |
|------|----------|
| **Intake** | **3 glass tiles** — half 100 ml / full 200 ml / big 250 ml (icon + label); **Set total** / **Edit goal** on add sheet |
| **Edit entry** | Tap water chip → same glass sheet; glass picks replace ml+label; **Set amount** numeric; **🗑** delete (meal-style); **Edit goal** hidden in edit mode |
| **Food Log bar** | H2O bar under Fi (always visible); tap bar → glass sheet; cyan fill; aligned macro grid (label 34px / value 98px) |
| **My Macros** | H2O progress bar (kcal → P → C → F → Fi → H2O); tap H2O bar → water-goal modal; **✎ Edit** opens manual targets incl. Water (ml) |
| **Goal** | Local default **2500 ml** in `water_goal_ml_v1` — **not** in coach `DailyMacroTarget`; synced across Food Log + My Macros |
| **Timeline** | Water chips merged chronologically with meals (time + label + ml) |
| **Store** | `water_log_v1` v2 (`{ version, days: Record<dayKey, WaterEntry[]> }`), `water_goal_ml_v1` |
| **Backup** | Keys not excluded — included in local/cloud backup; clinic export `includes: water` |
