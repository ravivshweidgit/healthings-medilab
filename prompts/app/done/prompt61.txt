## Prompt 61 — One-tap text meal save

**Status: done 2026-07-08** (phone-tested)  
**Builds on:** `done/prompt20.txt` (photo approve flow)

---

### Problem

Users fail to log meals: after AI parse they must find and tap **Save meal**. Extra taps feel like an approve step. Simple text meals should persist in one action.

---

### What shipped

| Path | Behavior |
|------|----------|
| **Text describe + send** | Analyze → if clean → **auto-save**, modal **stays open** to check time/items → **Done** |
| **Text + correction chat** | Refinements apply to saved meal; Done re-saves |
| **Recipe Log meal** | Same stay-open review |
| **Photo / + Add / − Remove** | Unchanged — merge preview → Approve → Save |
| **Meal issues** | Nutritionist alert → Edit / Save anyway |
| **Edit existing meal** | Explicit Save (no surprise auto-close) |

---

### Primary file

`app/src/components/FoodLogModal.tsx` — `tryAutoSaveTextMeal`, wired from `runMealAnalysis` (first text turn) + recipe prefill. Dashboard `handleFoodSaved` respects `close !== false`.
