### What shipped

#### 1) Textbook adaptive energy balance (code + prompt injection)

- `computeMacroEnergyPlan()` — single source of truth:
  - Anchor on **7d wearable burn** (not BMR).
  - Target loss rate: **0.3% / 0.5% / 0.7% BW/week** → **7700 kcal/kg**.
  - **% TDEE caps** (5–7% near goal, up to 20% / 500 kcal max).
  - **Adaptive taper** from **smart-scale 14d trend** (if losing faster than target → do not deepen cut).
  - Sex/age **absolute floor** + 95% of 7d eaten kcal floor.
- `formatEnergyBalanceBlock()` injected into macro revision context.
- `applyKcalEnergyFloor()` post-process if Gemini returns below plan.
- Prompt: use **ENERGY BALANCE (computed)** for JSON `kcal`.

#### 2) Cholesterol-first macro framing (not carb minimization)

- Prompt sections: **Primary goal**, **Fat derivation**, revised **Carbs**.
- Removed keto mislabel from rules summarizer and macro prompt.
- Deprecated blind **Constraints: aiContext** line (was injecting קטוגנית).
- Fiber rule clarified: “דלי פחמימה” = food quality, not minimize total carbs.

#### 3) Tiered CARB GUIDANCE (computed)

- `get7DayAverageEatenCarb_g()` + `formatCarbGuidanceBlock()`:
  - **≥50g eaten** → habit anchor ±10g (adherence).
  - **<50g + cholesterol primary** + no explicit low-carb rule → **50–80g** soluble-fiber band (start ~50g).
  - Explicit gram cap in My Rules → obey cap.
- User case: 33g eaten → suggest **50g** (not lock to 30g).
