## Prompt 80 — Hybrid activity: Withings distance walks + Withings bike (phone steps only when Watch Off)

**Status: done (2026-07-22)** — phone-tested Android (Samsung); Jul 21 Food Log **884 kcal** activity (was legacy **937**)  
**Builds on:** `done/prompt76` (phone health when watch off), `done/prompt70` (Food Log burn), `done/prompt73` (watch activity on manual weight), persistence parity rules

### Problem

Withings **workout kcal** (and Health Mate itself) disagreed ~**27–46%** across phones/accounts for the same rides. Cloud backups (`raviv.shweid@gmail.com` vs `raviv.shweid+withings-ios@gmail.com`, Jul 18–21 2026): gap was almost entirely **walk session kcal**; bikes were close. Legacy Watch On used passive + **all** workouts → inherited Withings walk noise.

### Product rule (locked + shipped)

| Mode | Signal | Source |
|------|--------|--------|
| **Watch On** | Walking / ambulatory energy | Withings **`getactivity` `distance`** × weight × **0.55** |
| **Watch On** | Walk / run / hike **workouts** | **Ignore** for burn (covered by daily distance) |
| **Watch On** | Bike + other non-distance sports | Withings **`getworkouts`** raw kcal |
| **Watch On** | Intraday passive calories | **Not** used for burn |
| **Watch Off** | Steps / walking energy | **Phone** (HC / Apple Health) — prompt76 |
| Either | Calibration UI | Deferred (factor `1` wired, no settings yet) |

Phone steps are **only** when Withings watch is absent.

### Burn formula

```text
# Watch On
walkKcal  = distanceKmToActiveKcal(distance_m / 1000, weightKg)   // 0.55 × kg × km
sportsKcal = Σ workout.kcal   // category ∉ {walk, run, hike}
activity  ≈ walkKcal + sportsKcal

# Watch Off (prompt76)
activity  ≈ stepsToActiveKcal(phoneSteps, …)
```
