## Prompt 67 — HR chart gap-break + shallow Withings sync

**Status: done (2026-07-16)** — Phone-tested (HR chart + Re-link action sheet).  
**Commits:** `2379239` (chart), `05d7f46` (shallow/deep sync).  
**Builds on:** **prompt45** (Withings HR sync hardening), **prompt21** (metrics persistence), MetabolicChart.

### Problem (user-reported)

1. **8D HR looked like a flat ~75 bpm line** from ~Jul 11 through Jul 16 while glucose stayed continuous. **12H** still showed real overnight HR variation (~52–82). Chart was bridging sparse/missing Withings samples into a fake continuous resting line; every-Nth downsample also crushed peaks on long windows.
2. **Full sync always pulled ~60 days of intraday HR** (and 128d workouts) even when persistence already held history — slow and unnecessary for routine refresh.

### What shipped

| Area | Change |
|------|--------|
| **Chart gaps** | Split glucose/HR paths when consecutive samples exceed a **viewport-scaled** gap (HR min **3h**; ~1/12 of window). Multi-day sync holes no longer draw as one flat red line. |
| **Chart downsample** | Min/max envelope per segment (replaces every-Nth) so overnight peaks survive on 8D/16D. |
| **Orphan dots** | Isolated HR samples as capped red dots (≤48) so sparse series cannot flood SVG. |
| **Shallow sync (default)** | When store is warm: merge **yesterday + today** only (`WITHINGS_SHALLOW_LOOKBACK_DAYS = 2`) for HR/intraday + workouts. Older persistence left untouched. |
| **Deep sync** | HR **60d** / workouts **128d** when: first link (empty HR), explicit user ask, or OAuth link success. |
| **UX** | Removed standalone **History** button. **Re-link** → action sheet: Normal sync / Deep history / Re-link account. |
