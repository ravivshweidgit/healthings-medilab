### A1 · F11 — Strip label + secondary-text contrast (AA)
- **Where:** `app/src/components/DashboardCollapseHeader.tsx` (shared strip header) + any
  local uppercase labels in `*Strip.tsx`; secondary/placeholder grays app-wide.
- **Do:** Darken the small-caps strip labels ("FOOD LOG", "GLUCOSE", …) and secondary text so

  check. Introduce a single `colors.textSecondary` / `colors.label` token if not present and

  per-strip grays.

### A2 · F10 — Off-brand purple Gallery tile

### A3 · F14 — Dashed borders on primary actions

### Spec (as implemented)

### B1 · F2 — Quick Start progress denominator changes mid-flow (P0)
- **Where:** `WelcomeQuickStartWizard.tsx` step model.
- **Problem:** Answering Yes to scale/watch/CGM inserts sync steps, so "X of N" grows
  11 → 12 → 13 mid-flow — the progress bar moves its own goalposts.
- **Do:** Pick one:
  - (a) Compute a **stable total** = max possible steps; skip inserted steps silently so N
    never shrinks/grows; or
  - (b) Drop the numeric "of N" and keep only the dot bar (dots can still grow, but no number
    to contradict).
  Prefer (a) if feasible. Logic-only; no copy risk beyond removing the number.

### B2 · F4 — Yes/No hidden below the fold (P1)
- **Where:** Quick Start decision steps (scale / watch / CGM) in `WelcomeQuickStartWizard.tsx`.
- **Problem:** Hero illustration + heading + body push the Yes/No buttons off-screen on first
  render; the "Tap Yes or No 👆" finger hint exists because users got stuck.
- **Do:** Reduce hero image height on decision steps and/or pin the Yes/No row so both options
  are visible above the sticky Back/Next footer without scrolling. Once visible by default,
  **remove the finger-emoji hint**. Keep the selected-state (navy fill) pattern.
- **Guard:** Fixed 2-button row must survive long labels + RTL (Yes/No are short, safe).

### B3 · F5 — Language gate: two disconnected language controls (P1)
- **Where:** First screen — `app/src/i18n/languageGate.ts` +
  `WelcomeQuickStartWizard.tsx` (gate layout).
- **Problem:** A 2-column text list of "Select language" translations sits up top (looks
  tappable, isn't); the real selector (flag tray) sits at the bottom with a big dead gap.
- **Do:** Collapse to **one control** — a grid of tappable cells, each = flag + native name
  (🇩🇪 Deutsch, 🇮🇱 עברית, …), single selected state. Keep one localized "Select language"
  header (may rotate through locales or follow current selection). Remove the separate text
  list and the dead space.
- **Guard:** Must fit **10 cells** + RTL names cleanly (2 cols × 5 rows works on small screens);
  native names include long ones (Português, Türkçe) — verify no clipping.
