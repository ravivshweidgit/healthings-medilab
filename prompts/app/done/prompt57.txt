### Problem

Quick Start step 2 (devices) and step 3 (weight) are not visible after onboarding. Users cannot see how the app routes body/activity/glucose, cannot optionally refine body fat % without re-running the wizard, and linking Withings on the dashboard did not refresh `source_config`.

---

### What shipped

| Area | Change |
|------|--------|
| **Your setup** | Read-only chips in My Profile from `source_config` + live Withings link state |
| **Body tracking** | Optional weight log + optional **body fat %** in My Profile only (no wizard steps, no prompts) |
| **Muscle** | Derived from weight + fat % — never asked |
| **Labels** | Dashboard body tiles: Withings vs manual; fat shows **est.** when AI-estimated |
| **Withings link** | `applyWithingsLinkToSourceConfig()` — body/BMR/HR paths upgrade without Quick Start |
| **Manual body** | `fat_pct_source: 'estimated' \| 'user'`; preserve user fat on weigh-in |

**Principles:** user responsibility only; trends from existing persistence (`manual_body_history_v1`, Withings store); manual history kept when Withings upgrades.
