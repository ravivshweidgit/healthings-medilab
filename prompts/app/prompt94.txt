## Hard constraints (do not fight)

- Glossary stays English; icons **augment**, never replace, clinical labels/units.
- **Do NOT touch emoji that is content, not chrome:**
  - Gemini prompt strings (`GeminiService.ts`), chat/export text (`mentorChatText.ts`,
    `mentorChatExport.ts`, `chatIntent.ts`), review copy (`ReviewService.ts`),
    lab/meal analysis text. These are model/exported content — leave emoji as-is.
  - `MENTOR_EMOJI` stays the source of truth for **text** (labels feeding exports/Gemini).
    Add a **separate** UI icon mapping; don't rip emoji out of the text helper.
- Clinic portal stays as-is (English, separate surface).
- Every icon needs an `accessibilityLabel` (localized where the label is user-facing).
- Motion only with purpose; icons are static.

## Phase 1 — Icon foundation (F7)

- **New file:** `app/src/theme/icons.tsx` (or `components/AppIcon.tsx`).

- Define a `strip → icon` map for dashboard sections (see Phase 2) and a

### P1.2 · Mentor avatars (UI only)
- **Where:** dashboard AI entry (`DashboardScreen.tsx` `activeMentorEmojis`), mentor chips

  minimal custom avatar set instead of 🩺🥗💪 **in the UI**. Keep `MENTOR_EMOJI` for text.
- **Guard:** chat message bodies and exports keep emoji — only the chrome affordances change.

### P1.3 · Chrome glyph pass (non-mentor)
- Replace UI emoji with Lucide equivalents where they are chrome, e.g.:
  - Water 💧 → `Droplet` (Food Log add-water)
  - PDF/report → keep the existing custom `PdfFileIcon` SVG (already on-brand — leave it)
  - Camera/Gallery already use emoji glyphs in tiles → optional: `Camera` / `Image` Lucide
- **Do NOT** change emoji inside chat/coach content.

## Phase 2 — Dashboard hierarchy (F6)

Problem: ~10 equal-weight white cards; only a small gray label differentiates them, so the
eye can't triage. Goal: clear tiers + per-strip icons so scanning is by shape.

### P2.1 · Per-strip icons
- Give each strip header a leading Lucide icon via `DashboardCollapseHeader` (add optional
  `icon` prop) using the registry map, e.g.:
  - Food Log → `UtensilsCrossed` · Glucose → `Activity`/`Droplet` · Trend & energy →
    `TrendingUp` · Profile & settings → `Settings`/`User` · Labs → `FlaskConical` ·
    Nutritionist sessions → `CalendarClock` · Rules → `ListChecks`
- Icon color = `textSecondary` (matches label); keep 44px tap target.

### P2.2 · Weight tiers (visual priority)
- **Primary** (larger / subtle accent / always near top): metrics summary card, AI chat
  entry, Food Log.
- **Secondary** (compact rows): Glucose, Trend & energy, Profile & settings, Labs,
  Nutritionist sessions.
- Implement with tokens (padding, header size, optional 1px accent or tint) — **not** by
  restructuring data flow. Keep collapse/expand behavior and AsyncStorage keys unchanged.
- **Guard (persistence-parity):** no new storage keys; do not change `*_EXPANDED_KEY`
  semantics or strip order persistence.

### P2.3 · Slim brand header (F18, folded in)
- Shrink the top HEALTHINGS.AI wordmark lockup on the dashboard so primary content rises
  above the fold. (Small, pairs naturally with the hierarchy work.)
