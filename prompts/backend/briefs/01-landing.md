## Ask the human for (before judging)

| Shot | Required |
|------|----------|
| Desktop above-the-fold (logo, H1, lead, store badges) | yes |
| Desktop full page (features / install / footer) | yes |
| Mobile ~390 full page (or stitch) | yes |

If missing, ask once, then proceed with what you have and mark gaps `needs render`.

---

## Investigate

1. **First viewport** — Does brand dominate? One headline? One support line? CTA group?
   Or is it crowded (install essay, too many links, weak hierarchy)?
2. **Conversion** — Are Play / TestFlight actions obvious for an alpha tester? Is “internal
   testing” clear without looking sketchy?
3. **Trust** — Does the page feel clinical-but-warm, or generic SaaS / unfinished?
4. **Typography & spacing** — Montserrat usage, lead length, rhythm, contrast on the blue
   gradient.
5. **Mobile** — Tap targets, badge scaling, wrap/overflow, footer density.
6. **Cross-links** — Help / clinic / privacy discoverability without stealing hero focus.

---

## Output for this pass

1. Short verdict on the landing only (3–5 sentences).
2. Findings **W…** using the format from `00-start-here.md`.
3. A **preferred hero sketch** in words or ASCII (brand / headline / support / CTAs /
   optional visual) — concrete enough for Auto later.
4. Note which findings should become a **landing-only** batch vs a shared design-system batch.
