## Prompt 17 — My Rules + Daily Macro Targets

### Goal
Two related features built together:

1. **My Rules** — user writes free-text dietary/lifestyle rules; AI summarises them
   into structured constraints shown in a collapsible row. The structured context
   is passed to every future AI call (body targets, macros, meal analysis, etc.)

2. **My Macros** — AI suggests daily protein/fat/carb/calorie targets using body
   data + body targets + the structured rules from "My Rules". Targets are shown
   as progress bars in the food log section.

## PART A — My Rules

### A1 — Storage (TargetService.ts)

```ts
export type UserRules = {
  rawText: string;           // exactly what the user typed
  summary: string;           // e.g. "Keto · Vegetarian · Diabetic · IF 12:8"
  constraints: string[];     // bullet list extracted by AI
  aiContext: string;         // clean 1-sentence AI-interpreted context
                             // passed to every other AI call
  analyzedAt: string;        // ISO timestamp
};

const USER_RULES_KEY = 'user_rules';

export async function getUserRules(): Promise<UserRules | null>
export async function saveUserRules(r: UserRules): Promise<void>
export async function clearUserRules(): Promise<void>
```

### A2 — GeminiService: summariseUserRules(rawText: string)

Single call, short prompt. Input: user's free-text string.

Prompt instructs Gemini:
```
The user has described their dietary and lifestyle rules in their own words.
Extract and structure this into the following JSON only, no markdown:

{
  "summary": "Short badge line, max 5 words, use · as separator e.g. Keto · IF 16:8",
  "constraints": ["< 50g carbs/day", "no meat", "eating window 12pm–8pm"],
  "aiContext": "One sentence max 20 words describing the diet for use in AI prompts"
}

User text: "<rawText>"
```

Config: `temperature: 0.1`, `maxOutputTokens: 8192`

### A3 — RulesStrip component (MacroTargetStrip.tsx — or separate RulesStrip.tsx)

States:

1. **idle** — no rules saved
   - Placeholder text: "Describe your diet and lifestyle..."
   - Multi-line `TextInput` (4 lines visible, scrollable)
   - Example hint: "e.g. keto diet, diabetic, no meat, IF 16:8"
   - "✨ Save & Summarise" button

2. **loading** — spinner "Understanding your rules…"

3. **active** — rules saved and summarised
   - Collapsed header shows `summary` (e.g. "Keto · IF 12:8")
   - Expanded shows:
     - Original text (greyed, smaller)
     - "AI understood:" section with constraint bullets (✓ each)
     - [Edit] button — returns to text input with existing text pre-filled
     - [Re-summarise] — re-runs AI on current text

## PART B — My Macros

### B1 — DailyMacroTarget type (TargetService.ts)

```ts
export type DailyMacroTarget = {
  protein_g: number;
  fat_g: number;
  carb_g: number;
  kcal: number;
  diet_label: string;         // e.g. "Ketogenic", "High Protein", "Mediterranean"
  reasoning: string;          // max 15 words
  rulesContext: string;       // aiContext from UserRules at time of analysis
  aiSuggested: {              // original AI values, preserved even after user edits
    protein_g: number;
    fat_g: number;
    carb_g: number;
    kcal: number;
  };
  analyzedAt: string;
};

const MACRO_TARGET_KEY = 'daily_macro_target';

export async function getMacroTarget(): Promise<DailyMacroTarget | null>
export async function saveMacroTarget(t: DailyMacroTarget): Promise<void>
export async function clearMacroTarget(): Promise<void>
```

### B2 — GeminiService: suggestDailyMacros()

```ts
type MacroInput = {
  weight_kg: number;
  fatMass_kg: number;        // to compute lean mass
  muscleMass_kg: number;
  bmr_kcal: number;
  estimatedBurn_kcal: number | null;
  heightCm: number;
  age: number;
  gender: string;
  bodyTarget: {
    targetWeight_kg: number;
    targetFatPct: number;
    targetMuscleMass_kg: number;
  } | null;
  rulesContext: string;      // aiContext from UserRules — or '' if not set
};
```

Prompt sent to Gemini (compact, no markdown in response):
```
Fitness nutrition AI. Output ONLY valid JSON.

METRICS:
Weight: {weight_kg} kg | Lean mass: {lean_kg} kg | Fat%: {fatPct}%
BMR: {bmr} kcal | Est. daily burn: {burn} kcal
Age: {age} | Gender: {gender} | Height: {heightCm} cm
Goal: {targetWeight_kg} kg / {targetFatPct}% fat / {targetMuscleMass_kg} kg muscle
Dietary rules: {rulesContext}

OUTPUT:
{"protein_g":160,"fat_g":140,"carb_g":30,"kcal":1960,"diet_label":"Ketogenic","reasoning":"Max 15 words here."}

RULES:
- Protein: 1.6–2.2g × lean_mass_kg
- Respect dietary rules as highest priority
- Calorie deficit: 300–500 kcal below burn for fat loss
- diet_label: Ketogenic/Vegan/High Protein/Mediterranean/Balanced/Custom
```

Config: `temperature: 0.2`, `maxOutputTokens: 8192`

### B3 — MacroTargetStrip component

New component: `app/src/components/MacroTargetStrip.tsx`

Same collapsible pattern as WeightTargetStrip.

States:

1. **idle** — no target set
   - Note if no UserRules set: "Add your dietary rules above for better results"
   - "✨ Ask AI to set my macros" button (disabled if no body scan data)

2. **loading** — spinner "Calculating your macros…"

3. **suggestion** — AI result:
   - `diet_label` badge + reasoning sentence
   - 4 columns: **Protein / Fat / Carbs / Calories**
   - Accept / Edit buttons

4. **editing** — 4 text inputs (P / F / C / kcal) with AI suggestion beside each

5. **active** — compact display:
   ```
   Ketogenic                              ✎ edit
   P  ████████░░░░  120g / 160g
   C  █░░░░░░░░░░░   18g /  30g
   F  ███████░░░░░   98g / 140g
   ─────────────────────────────────────
   1,490 / 1,960 kcal
   ```
   - Bar fill = actual / target (0–100%)
   - Bar turns red if actual > target × 1.1 (over by 10%+)
   - "Re-analyze" button at bottom

Props:
```ts
type MacroTargetProps = {
  actualProtein_g: number | null;
  actualFat_g: number | null;
  actualCarb_g: number | null;
  actualKcal: number | null;
  weightKg: number | null;
  fatMassKg: number | null;
  muscleMass_kg: number | null;
  bmr_kcal: number | null;
  estimatedBurn_kcal: number | null;
  heightCm: number | null;
  age: number | null;
  gender: string | null;
  bodyTarget: BodyTarget | null;
  userRules: UserRules | null;
};
```

### B4 — FoodMacroStrip update

When a `DailyMacroTarget` exists, update the existing P/C/F bars:
- Bar max = target value (replaces the rolling max)
- Label beside bar: `120g / 160g` (actual / target)
- Calorie row: `1,490 / 1,960 kcal`

New optional prop: `macroTarget?: DailyMacroTarget | null`
