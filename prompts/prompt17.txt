## Prompt 17 — My Mentors + My Rules + Daily Macro Targets

### Goal
Three related features built together:

1. **My Mentors** — user picks 1–3 AI mentor personas (Doctor / Nutritionist / Coach).
   Every AI call is prefixed with the combined mentor system prompt. At least one
   mentor is always required. Default: Coach + Nutritionist.

2. **My Rules** — user writes free-text dietary/lifestyle rules; AI summarises them
   into structured constraints. The structured context is passed to every AI call.

3. **My Macros** — AI suggests daily protein/fat/carb/calorie targets using body
   data + body targets + mentor persona + structured rules. Shown as progress bars
   in the food log section.

## PART A — My Mentors

### A1 — Storage (TargetService.ts)

```ts
export type MentorType = 'doctor' | 'nutritionist' | 'coach';

// Stored as array — at least one always required
// Default: ['coach', 'nutritionist']
const MENTOR_KEY = 'user_mentors';

export async function getMentors(): Promise<MentorType[]>
export async function saveMentors(mentors: MentorType[]): Promise<void>
```

### A2 — Mentor system prompt builder (GeminiService.ts)

```ts
export function buildMentorSystemPrompt(mentors: MentorType[]): string
```

Rules:
- Single mentor → that mentor's persona only
- Multiple mentors → combined persona with priority order: Doctor > Nutritionist > Coach
  (Doctor's safety guidance always wins conflicts)
- All three → "You are a medical doctor, nutritionist, and fitness coach AI.
  Prioritise health safety, then food quality, then performance."

Persona descriptions:

| Mentor | System prompt fragment |
|---|---|
| 🩺 Doctor | "You are a medical doctor AI. Prioritise health risk reduction, evidence-based guidelines, and patient safety. Be conservative and clinically precise." |
| 🥗 Nutritionist | "You are a certified nutritionist AI. Focus on food quality, macronutrient balance, micronutrients, and sustainable eating patterns." |
| 💪 Coach | "You are a professional fitness coach AI. Focus on body composition, muscle preservation, progressive fat loss, and performance goals." |

### A3 — MentorStrip component (MentorStrip.tsx)

Simple collapsible row. Expanded view:

```
Your AI mentors  (select at least one)

┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 🩺           │  │ 🥗           │  │ 💪           │
│   Doctor     │  │ Nutritionist │  │    Coach     │
│ conservative │  │ food quality │  │  performance │
└──────────────┘  └──────────────┘  └──────────────┘
  not selected       ✓ selected        ✓ selected
```

- Each mentor card is a Pressable toggle
- Selected = filled background (accent colour), not selected = outlined
- Tapping the last selected mentor shows hint: "At least one mentor required"
- Changes save immediately (no Save button needed — single field)
- Collapsed header shows emoji of selected mentors e.g. "💪 Coach · 🥗 Nutritionist"

## PART B — My Rules

### B1 — Storage (TargetService.ts)

```ts
export type UserRules = {
  rawText: string;           // exactly what the user typed
  summary: string;           // e.g. "Keto · Vegetarian · Diabetic · IF 12:8"
  constraints: string[];     // bullet list extracted by AI
  aiContext: string;         // clean 1-sentence AI-interpreted context
                             // passed to every other AI call
  analyzedAt: string;        // ISO timestamp
};

const USER_RULES_KEY = 'user_rules';

export async function getUserRules(): Promise<UserRules | null>
export async function saveUserRules(r: UserRules): Promise<void>
export async function clearUserRules(): Promise<void>
```

### B2 — GeminiService: summariseUserRules()

```ts
export async function summariseUserRules(
  rawText: string,
  mentors: MentorType[]
): Promise<UserRules>
```

The mentor system prompt is prepended so the AI interprets rules through the
right lens (a Doctor reads "diabetic" differently than a Coach would).

Prompt:
```
{mentorSystemPrompt}

The user has described their dietary and lifestyle preferences in their own words.
Extract and structure this into the following JSON only, no markdown:

{"summary":"Keto · IF 16:8","constraints":["< 50g carbs/day","eating window 12-8pm"],"aiContext":"Ketogenic diet with 16:8 intermittent fasting, prioritising fat loss."}

Rules:
- summary: max 5 words, use · as separator
- constraints: max 5 items, max 8 words each
- aiContext: max 20 words, will be used in future AI prompts

User text: "{rawText}"
```

Config: `temperature: 0.1`, `maxOutputTokens: 8192`

### B3 — RulesStrip component (RulesStrip.tsx)

States:

1. **idle / editing** — text input visible
   - Multi-line `TextInput` (4 lines, scrollable)
   - Placeholder: "e.g. keto diet, diabetic, no meat, IF 16:8"
   - "✨ Save & Summarise" button

2. **loading** — spinner "Understanding your rules…"

3. **active** — rules saved:
   - Collapsed header shows `summary` (e.g. "Keto · IF 16:8")
   - Expanded shows:
     - Original text (greyed, 12px)
     - "AI understood:" section — constraint bullets with ✓
     - [Edit] button → returns to text input pre-filled

## PART C — My Macros

### C1 — DailyMacroTarget type (TargetService.ts)

```ts
export type DailyMacroTarget = {
  protein_g: number;
  fat_g: number;
  carb_g: number;
  kcal: number;
  diet_label: string;         // e.g. "Ketogenic", "High Protein", "Mediterranean"
  reasoning: string;          // max 15 words
  rulesContext: string;       // aiContext from UserRules at time of analysis
  mentors: MentorType[];      // mentors active at time of analysis
  aiSuggested: {              // original AI values — preserved after user edits
    protein_g: number;
    fat_g: number;
    carb_g: number;
    kcal: number;
  };
  analyzedAt: string;
};

export async function getMacroTarget(): Promise<DailyMacroTarget | null>
export async function saveMacroTarget(t: DailyMacroTarget): Promise<void>
export async function clearMacroTarget(): Promise<void>
```

### C2 — GeminiService: suggestDailyMacros()

```ts
type MacroInput = {
  weight_kg: number;
  fatMass_kg: number;
  muscleMass_kg: number;
  bmr_kcal: number;
  estimatedBurn_kcal: number | null;
  heightCm: number;
  age: number;
  gender: string;
  bodyTarget: { targetWeight_kg: number; targetFatPct: number; targetMuscleMass_kg: number } | null;
  rulesContext: string;       // UserRules.aiContext or '' if not set
  mentors: MentorType[];
};
```

Mentor system prompt prepended. Then:
```
METRICS:
Weight: {w} kg | Lean mass: {lean} kg | Fat%: {fat}%
BMR: {bmr} kcal | Est. daily burn: {burn} kcal
Age: {age} | Gender: {gender} | Height: {h} cm
Goal: {targetWeight} kg / {targetFat}% fat / {targetMuscle} kg muscle
Dietary rules: {rulesContext}

OUTPUT (JSON only, no markdown):
{"protein_g":160,"fat_g":140,"carb_g":30,"kcal":1960,"diet_label":"Ketogenic","reasoning":"Max 15 words."}

RULES:
- Protein: 1.6–2.2g × lean_mass_kg
- Respect dietary rules as highest priority
- Calorie deficit 300–500 kcal below burn for fat loss
- diet_label: Ketogenic/Vegan/High Protein/Mediterranean/Balanced/Custom
```

Config: `temperature: 0.2`, `maxOutputTokens: 8192`

### C3 — MacroTargetStrip component (MacroTargetStrip.tsx)

Same collapsible pattern as WeightTargetStrip.

States:

1. **idle** — no target set
   - If no mentors set: warn "Select a mentor above first"
   - "✨ Ask AI to set my macros" button (disabled if no body scan data)

2. **loading** — "Calculating your macros…"

3. **suggestion** — AI result:
   - `diet_label` badge + reasoning
   - 4 columns: Protein / Fat / Carbs / Calories
   - Accept / Edit buttons

4. **editing** — 4 inputs (P / F / C / kcal) with AI suggestion beside each

5. **active** — macro bars:
   ```
   Ketogenic                              ✎ edit
   P  ████████░░░░  120g / 160g
   C  █░░░░░░░░░░░   18g /  30g
   F  ███████░░░░░   98g / 140g
   ─────────────────────────────────────
   1,490 / 1,960 kcal
   ```
   - Bar turns red if actual > target × 1.1
   - "Re-analyze" button at bottom

### C4 — FoodMacroStrip update

New optional prop: `macroTarget?: DailyMacroTarget | null`

When set:
- Bar max = target value
- Labels show `actual / target` (e.g. "120g / 160g")
- Calorie row: `1,490 / 1,960 kcal`

### Step D — DashboardScreen integration
