# Logo direction

**Theme:** knowledge + health  
**Book** = knowledge · **Heart** = care/health · **Rod of Asclepius** = medicine  

## Optimized picks (2026-07-30)

| File | Concept | Knowledge | Health |
|------|---------|-----------|--------|
| **`logo-knowledge-health-optimized.png`** ★ | Soft book + page lines; heart L / Asclepius R (~55–60%) | Book | Heart + Asclepius |
| `logo-knowledge-health-split-opt.png` | Soft book + page lines; split heart across gutter | Book | Heart only |

**Working final:** `book-soft-final.png` → copy of ★ optimized (heart + Asclepius).

**Color locked (2026-07-30):** **Navy primary** `#1a2b4a` — main lockup. Accent / on-dark remain secondary variants only.

**Clean lockup preferred:** `lockup-leaf-asclepius.png` — book with **leaf** (left) + **Asclepius** (right) + HEALTHINGS.AI.  
Leaf = health preserved in knowledge; Asclepius = medicine. No tagline on primary mark.  
Philosophy optional for splash: *"Like to get to know you well" — Howard Jones*.

**On-dark note:** knock-out heart/Asclepius can vanish into navy — prefer white filled symbols when polishing for production.

**Why ★ wins for “knowledge and health”:** split heart is elegant but drops the medical Asclepius cue; heart + Asclepius states both ideas in one glance.
